# 국내주식 전략 알림 · 시장 백테스트

KOSPI·KOSDAQ 전일 거래대금 1위 종목을 실제 데이터로 선정해 다음 거래일 1분봉을 추적하는 로컬 웹 앱입니다. 주문은 실행하지 않고 텔레그램 알림만 보냅니다. 합성 데이터나 예시 종목은 화면과 시장 백테스트에 사용하지 않습니다.

## 전략 01

- 시장별 전 거래일 KRX 전종목 `거래대금` 1위 한 종목을 다음 거래일에 추적
- 당일 고점 또는 당일 시가 대비 8%, 10%, 12%, 15% 하락 가격 도달 시 단계별 매수
- 각 단계는 선택 시장에 배정된 최초 자본의 25%
- 보유 수량의 가중평단 대비 -5% 전량 손절, +4% 전량 익절
- 같은 1분봉에서 손절·익절 가격이 모두 닿으면 보수적으로 손절 우선
- 장 마감까지 남은 포지션은 마지막 1분봉 종가로 청산
- KOSPI와 KOSDAQ을 함께 테스트하면 초기자본을 두 시장에 같은 비율로 배정

## 전략 02

전략 01과 진입·분할매수·TP·SL 규칙은 같고 장마감 강제청산만 하지 않습니다. 포지션을 다음 거래일로 이월해 TP 또는 SL 도달 시에만 청산하며, 백테스트 종료 시 남은 포지션은 매도하지 않고 최종 가격으로 평가합니다.

## 실행

Python 3.11 이상이 필요합니다.

- macOS/Linux: `start_unix.sh` 실행
- Windows: `start_windows.bat` 더블클릭
- 대시보드: `http://127.0.0.1:8765`

첫 실행은 `config.json`을 자동 생성합니다. 자격정보를 입력하기 전까지 대시보드는 열리지만 가짜 가격은 표시하지 않습니다.

## 실제 데이터 연결

`config.json`에서 `mode`를 `kis`로 바꾸고 다음 값을 입력합니다.

```json
{
  "mode": "kis",
  "kis_app_key": "한국투자증권 Open API App Key",
  "kis_app_secret": "한국투자증권 Open API App Secret",
  "krx_id": "KRX Data Marketplace 아이디",
  "krx_password": "KRX Data Marketplace 비밀번호",
  "telegram_bot_token": "텔레그램 봇 토큰",
  "telegram_chat_id": "텔레그램 채팅 ID"
}
```

파일 대신 `KIS_APP_KEY`, `KIS_APP_SECRET`, `KRX_ID`, `KRX_PW`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `BOT_MODE=kis` 환경변수를 사용할 수 있습니다. 환경변수가 같은 항목보다 우선합니다. 실제 비밀값이 든 `config.json`은 외부에 공유하지 마세요.

## 시장 백테스트

사이드바의 **시장 백테스트**에서 기간, 초기자본, KOSPI/KOSDAQ, 왕복 비용률을 입력합니다. 프로그램은 각 거래일마다 다음 작업을 수행합니다.

1. KRX 일별 전종목 데이터에서 직전 거래일 거래대금 1위를 시장별로 선정합니다.
2. 선정 종목의 다음 거래일 실제 KIS 1분봉을 불러옵니다.
3. 4단계 매수와 가중평단 손절·익절을 시간 순서대로 체결합니다.
4. 최종자본, 누적수익률, 거래 수, 승률, 최대낙폭을 계산합니다.
5. 회사명이 표시된 자산 곡선, 거래별 1분봉 매수·매도 마커, 정확한 날짜·시각·수익률을 HTML 리포트로 남깁니다.

API 호출량 때문에 긴 기간은 시간이 걸립니다. 조회한 거래대금 1위와 분봉은 `data/backtest_cache`에 저장되어 같은 구간을 다시 실행할 때 재사용됩니다. 완료된 분봉만 사용하므로 종료일은 오늘 이전이어야 하며, 한 번의 요청 기간은 최대 1년입니다.

## 화면 구분과 확장

- **실시간 알림:** 오늘의 실제 대상, 날짜·시각 축이 있는 1분봉 차트, 매수/손절/익절 신호, 수동 평단, 텔레그램 상태
- **시장 백테스트:** 시장 단위 조건 입력, 조회 진행률, 자본 결과, 상세 HTML 리포트
- 전략 구현은 `market_watcher/strategies/`에 분리되어 있습니다. 새 전략 클래스를 추가하고 전략 빌더에 등록하면 사이드바와 엔진을 확장할 수 있습니다.
